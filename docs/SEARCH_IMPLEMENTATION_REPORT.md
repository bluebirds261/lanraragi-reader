# 搜索增强实施记录

日期：2026-09-15。基线：`0a9d92f`。对应 `SEARCH_EXPERIENCE_ENHANCEMENT_PLAN.md`。

## 已实现

- **查询与补全**：新增 LANraragi 查询编解码；逗号 AND、整条件引号/末尾 `$` 精确匹配、排除、通配符、页数/阅读页条件；生成标签不再沿用 E-Hentai 引号格式。无 namespace 标签正常生成。按光标片段或选择区替换，保留后续条件；重复选择去重，已有相反条件时提示先移除；不支持的 `~` 和不完整引号给出错误。
- **搜索会话**：页面持有可保存的草稿/选区、已提交查询和编辑/结果/关闭状态；未提交草稿不修改图库。系统返回处理键盘、管理、多选及取消编辑。提交立即更新查询并收焦点，历史写入不阻塞搜索。同查询在途提交去重。
- **搜索 UI**：保留玻璃入口，常驻提交按钮与直接搜索行；开合过渡保留退出子树，圆角过渡，宽屏输入区上限 720dp。进入结果后点击输入可再编辑；精确条件显示可移除摘要。输入支持 Enter、Esc 和向下移动焦点。入口有已生效筛选标记与省略显示。
- **历史**：20 条最近优先、原子更新；按服务器/本地作用域保存；旧历史单独保留。默认两行、展开全部、管理模式、隐藏与暂停分别持久化；点击重搜、菜单编辑/复制/删除、删除撤销、清空确认。可识别的精确标签历史显示译名，原始查询保持原文。
- **热门标签**：当前服务器或本地书架频次；过滤机器 namespace、namespace 中文筛选、默认 15 项/更多最多 60 项、频次说明、长按直接搜索/排除菜单。持久缓存按作用域隔离，TTL 30 分钟；显示更新时间、加载、缓存降级与重试。图库刷新触发重新获取统计。
- **联想**：仅检索当前片段，负号独立保存；220ms 防抖，IME composition 时不重写/查询，原文/译文匹配高亮；使用词库候选，补充当前库标签缓存，无词库仍能普通搜索。保留 TagSuggestion 模型，以历史作为个人频次来源。词库快照复用，词库更新/清除后失效；大批候选排名周期性响应取消。
- **数据正确性**：远端已通过搜索/分类筛选的结果不再按整串 contains 再过滤；本地使用独立条件评估。匹配数与全库数分开，未知总数不冒用全库数。来源切换和请求代次隔离；取消或过期请求不能覆盖新状态。
- **分页**：生产远端适配器提供真实 offset 分页；不再预先抓尽远端结果。查询会话保存实际来源 offset 和 UI 页起点，服务器短页可直接展示且不跳项；触底只追加，刷新重建会话。混合来源明确分组为本地在前、服务器在后，各自排序，不宣称局部数据已全局混排；远端失败时保留本地结果并标记总数未知。
- **结果组件复用**：图库与搜索面共同使用 LibraryResultsContent，共享外层滚动状态；统一 list/grid/compact、封面、单行本卷数、点击路径、多选反馈、刷新、首屏加载/失败/空态、追加失败重试与终点。开合期间只挂载一个活跃列表；底层顶栏不进入搜索面的焦点链。
- **来源入口**：在既有筛选面板加入全部/服务器/本地，不另建第二套搜索筛选表单。搜索结果头展示来源、分类、额外条件、排序，以及总数/已加载数。

## 实施边界与待设备验收

1. 本次交付已串通搜索全流程。动画采用同位置开合与圆角过渡，尚未基于真机帧数据完成逐像素共享容器形变校准；宽屏探索区目前是居中单列，未做历史/热门双栏。
2. 本地档案与 metadata 采用两次批量读取并在查询会话内缓存，已消除逐档案 metadata 查询和每页重新读取；不是完整 SQL 条件下推分页。大本地库的内存峰值和读取时延需设备测量后决定是否继续下推。
3. 混合来源采用明确分组，保持服务器组原始排序。为提供错误及数量信息，混合首屏仍等待第一批远端请求完成或失败；尚未让两来源独立流式首屏更新。
4. 无法可靠表示为服务端精确条件的保留字符标签会提示手动编辑，不承诺任意字符转义。`~` 不被转换成 OR；中文自然语言不会静默替换为标签。
5. 语法和真实接口一致性目前以本地 LANraragi 源码及契约样例测试为依据；仍需实际服务端验证特殊字符、分类、分组单行本及 1k/10k 档案规模。
6. 结果视图复用既有卡片能力，未新增 E-Hentai 图搜、URL 直达、语义检索或另一套预设存储。
