## 本轮修复

1. **空输入提示未居中**：输入容器增加 CenterStart 对齐，placeholder 与正文使用相同 bodyLarge 样式；复测输入提示与光标基线对齐。
2. **结果数量被按钮挤换行**：将数量置于独立整行，将简短范围摘要与操作按钮放在下一行；复测 0 项和非空结果数量不再被横向按钮挤压。
3. **撤销被键盘遮挡/重复节点**：搜索面 Snackbar 增加 IME padding，底层图库在搜索期间不再挂载同一 SnackbarHost；最终复测仅有一份撤销按钮，位于键盘上方，可点击恢复历史。

修复后 `:app:assembleDebug` 通过；全部 304 项 JVM 测试通过（`tools/Run-LocalUnitTests.ps1`，记录 `.verify/acceptance-tests.log`）。最终包已覆盖安装。读取 crash buffer 未发现记录（`.verify/acceptance-crash.log`）。
